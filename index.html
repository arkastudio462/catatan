    Cloudflare R2 dan data

    Koneksi Cloudflare R2

    Gambar bukti diunggah ke bucket R2 kamu. Pastikan bucket sudah diatur akses publiknya.

    Cara mendapatkan kredensial R2
    1. Buka dash.cloudflare.com → R2 Object Storage.
    2. Buat bucket baru atau gunakan bucket yang sudah ada.
    3. Di tab Settings, aktifkan Public Access (R2.dev subdomain atau custom domain).
    4. Di tab API Access, buat S3 API Token (bukan Management API).
    5. Salin Access Key ID dan Secret Access Key.
    6. Endpoint ada di bawah judul S3 API di halaman token.

    Data pengeluaran

    Catatan tersimpan di browser ini. Buat cadangan berkala, terutama sebelum membersihkan data browser.
